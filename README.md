# Portfolio Project

A modern, responsive portfolio website built with React and Vite.

## Description

This project is a personal portfolio website designed to showcase projects, skills, and contact information. It features a dark-themed design with glassmorphism effects, smooth scrolling navigation, and responsive layout for all devices.

### Key Features

- **Hero Section**: Dynamic introduction with animated background elements.
- **Projects Showcase**: Grid layout displaying featured work with hover effects.
- **About & Skills**: Detailed bio and categorized technical skills.
- **Contact Area**: Simple call-to-action and social links.
- **Responsive Design**: Optimized for mobile, tablet, and desktop screens.

## Technologies Used

- [React](https://reactjs.org/) - JS Library for building user interfaces
- [Vite](https://vitejs.dev/) - Next Generation Frontend Tooling
- [CSS3](https://developer.mozilla.org/en-US/docs/Web/CSS) - Custom styling with CSS Variables

## Getting Started

### Prerequisites

- Node.js (version 16 or higher recommended)
- npm (Node Package Manager)

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd tpgitportfolio
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

### Running the Application

To start the development server:

```bash
npm run dev
```

The application will be available at `http://localhost:5173`.

### Building for Production

To create a production build:

```bash
npm run build
```

The built files will be in the `dist` directory.
